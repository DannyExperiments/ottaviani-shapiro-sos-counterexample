# Evidence boundary

Public evidence consists of the canonical proof, sanitized audit summaries,
exact dependency-free verification sources, expected outputs, and integrity
ledgers. Raw conversations, private receipts, local paths, screenshots, and
third-party source PDFs are excluded.

The deterministic public evidence bundle also excludes the assembled
Aristotle request ZIP. Its two public-safe source documents remain separately
readable under `formalization/aristotle/`; no returned formalization certificate
exists.
