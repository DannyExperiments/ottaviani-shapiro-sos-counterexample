# Dependency map

```text
sum of squares equals zero
  -> each quadratic equation holds
  -> sign exclusions force t in {0,...,8}
  -> exact two-zero/seven-positive radicand profile
  -> 2^7 solutions per t-fiber
  -> nine disjoint fibers
  -> 1152 real zeros
  -> 1152 > 2^10
  -> conjectured equality refuted
```

The complex complete-intersection argument and general even-degree family are
out of scope for this first request.
