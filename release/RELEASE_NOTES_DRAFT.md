# Draft release notes

This candidate supplies an explicit quartic sum of squares in ten variables
with exactly 1152 isolated real zeros. It refutes the Ottaviani--Shapiro
conjecture `tilde#(2k,l)=k^l` by proving
`tilde#(4,10)>=1152>1024` and gives an audited even-degree lower-bound family.

The release does not determine the exact extremal function, claim absolute
historical priority, assert human peer review, or claim full formal
verification.
